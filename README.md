# 老挝ERP｜东南亚摩托车车行管理系统

## 演示地址
http://43.133.108.250:8501
> 测试原型，服务器部署在曼谷，国内访问不稳定；仅用于演示，不含真实业务数据。

## 项目介绍
分为两个版本：
V6.3 网页云端版：多账号登录，老板/销售员权限分开，库存管理、销售开单，支持官方汇率+民间汇率记录。
V6.2 本地单机版：电脑直接运行，断网也可以记账。

## 功能清单
✅ 摩托车库存登记、查询
✅ 销售单录入
✅ 用户权限分级（老板、销售员）
✅ 双汇率记录（官方汇率、民间汇率）
